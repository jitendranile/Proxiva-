# Proxiva

Proxiva is a Local Service Marketplace Platform that connects customers with nearby service providers.

# Features

- User Registration & Login
- Customer Dashboard
- Service Booking
- Provider Management
- Booking Status Tracking
- Review & Rating System
- Secure Authentication

# Tech Stack

- Java
- Spring Boot
- Thymeleaf
- MySQL
- HTML
- CSS
- JavaScript
